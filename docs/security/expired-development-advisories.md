## Verification procedure

Use Node 22 and the pinned pnpm version. Use a clean installation for review.

1. Run `pnpm install --frozen-lockfile`.
2. Run `pnpm run security:deps:compat`.
3. Run `pnpm run security:deps:gate`.
4. Run the affected contract, auth and SDK checks.
5. Record the final source SHA and logs in the PR.
6. Obtain independent engineering and Security review before merge.

Remove each patch when a compatible upstream release implements its fix. Replace the exact version and advisory disposition together. Recheck the affected consumers. Do not remove a patch while retaining its accepted disposition. Rollback restores the prior vulnerable source and expired exceptions; it is not a passing release state.
